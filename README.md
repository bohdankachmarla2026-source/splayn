# Splayn — 3D-друк на замовлення

Сайт, де клієнт описує деталь словами або завантажує свій файл (STL, 3MF, OBJ) і одразу бачить ціну друку.

- Ціну рахує справжній слайсер Bambu Studio під Bambu Lab P1S (стіл 256×256×250 мм, деревоподібні підтримки). Тарифи — у `server/app.py`: пластик 2 грн/г (з підтримками), час друку 40 грн/год, 50 грн за замовлення.
- У картці з ціною є 3D-перегляд моделі на столі, вибір пластику, якості друку й кольору.
- Пошук готових моделей на Printables розуміє українську й російську, відсіює моделі не за темою.
- Якщо текст набрано в англійській розкладці («ot dfhsfynb»), він сам стає кирилицею («ще варіанти»).
- ШІ-помічник (Claude) працює, якщо додати ключ API. Без ключа працює базовий режим: пошук, завантаження файлів і розрахунок.

## Що потрібно

- macOS (шлях до слайсера зараз прописаний для Mac у `server/slicer.py`, `SLICER_BIN`).
- [Bambu Studio](https://bambulab.com/en/download/studio) у `/Applications/BambuStudio.app`.
- Python 3.9 або новіший.

## Запуск

З папки проєкту, один раз:

```bash
python3 -m venv server/.venv
server/.venv/bin/pip install -r server/requirements.txt
```

Щоразу:

```bash
server/.venv/bin/python server/app.py
```

Потім відкрийте http://127.0.0.1:8000/

### Ключ для ШІ-помічника (необов'язково)

```bash
sh server/set-key.sh
```

Ключ зберігається у `server/.env`. Цей файл не потрапляє на GitHub: у кожного свій ключ, нікому його не надсилайте.

## Структура

| Папка / файл | Що там |
| --- | --- |
| `site/` | Сторінки: `index.html` (головна), `start.html` (чат-помічник), `upload.html` (калькулятор), `catalog.html` |
| `site/css/main.css` | Стилі; кольори, шрифти, радіуси — токени в `:root` |
| `site/js/start.js` | Чат, картки з ціною і моделями |
| `site/js/viewer.js` | 3D-перегляд (three.js) |
| `site/js/layout-fix.js`, `layout-model.js` | Виправлення розкладки; модель будує `tools/build_layout_model.py` |
| `server/app.py` | Сервер: сторінки й API (опис запитів — на початку файлу) |
| `server/slicer.py`, `base.ini` | Виклик Bambu Studio і налаштування друку |
| `server/model_search.py` | Переклад запиту й відбір моделей за темою |
| `server/printables.py` | Пошук і завантаження моделей з Printables |
| `server/assistant.py` | ШІ-помічник |
| `server/uploads/` | Файли клієнтів (не потрапляє на GitHub) |

## Як працюємо разом

1. Перед роботою беремо свіжу версію: `git pull`.
2. Кожне завдання — в окремій гілці, не в `main`.
3. Готову гілку відправляємо на GitHub і відкриваємо pull request.
4. Другий переглядає зміни, перевіряє і зливає в `main`.
5. Домовляємося, хто над якою частиною працює, щоб рідше правити ті самі файли.
